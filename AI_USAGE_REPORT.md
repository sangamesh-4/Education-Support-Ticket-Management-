AI Tool Used

ChatGPT

I used ChatGPT as a development assistant during the project for discussing implementation ideas, debugging issues, and improving documentation.

What I Asked AI to Do

I mainly used ChatGPT for:

1. Breaking down the assignment into practical modules and workflows.

2. Getting implementation suggestions for FastAPI, React, PostgreSQL, authentication, and ticket management.

3. Debugging issues that came up while running and testing the application.

I made the final implementation decisions based on the assignment requirements and my own testing.

Prompt That Was Most Useful

"I need to build a Student Support & Ticket Management system where students can raise requests and staff can assign, prioritize, process, and resolve them. Help me design a practical workflow with Student, Staff, and Manager roles, including ticket statuses, priorities, SLA, activity history, and management visibility."

This helped me convert the business problem into a clear and manageable application workflow.

Code Generated by AI

ChatGPT provided suggestions and code examples for parts of:

• FastAPI routes and database models

• Authentication and role-based access

• Ticket management logic

• SLA and activity tracking

• React API integration and UI behavior

I reviewed and integrated the relevant parts instead of using the generated output without testing it.

Code I Modified

I modified the implementation based on the actual project requirements and testing.

Some important changes included:

• Added CORS configuration for the React frontend.

• Configured PostgreSQL to use port 5433 because another PostgreSQL setup was already using port 5432.

• Pinned bcrypt==4.0.1 after encountering a password-hashing compatibility issue.

• Changed ticket number generation to millisecond precision to reduce the possibility of duplicate ticket numbers.

• Adjusted frontend API handling and role-based UI behavior.

AI Output That Was Wrong

During development, the frontend initially showed:

Failed to fetch

The backend was running, but the React frontend could not communicate with it correctly.

How I Identified the Problem

I tested the application through the browser and checked the backend API separately.

The backend was responding correctly, so I narrowed the problem down to the communication between the React development server and FastAPI.

I then checked the backend configuration and identified that CORS had not been configured for the frontend development server.

How I Fixed It

I added FastAPI CORS middleware and allowed the local React development origins:

http://localhost:5173

http://127.0.0.1:5173

After restarting the backend, I tested the login flow again and confirmed that the frontend and backend were communicating correctly.

I also tested the main ticket workflow, including ticket creation, assignment, status changes, priority changes, pending status, resolution, closure, activity history, and Staff and Manager access.
